# AMRC — Visual Chapter Guide

A mobile-friendly visual study guide for AMRC (Advanced Methods for Regression
and Classification, TU Wien — Prof. Dr. Peter Filzmoser).

The guide is a single self-contained `index.html` page hosted on GitHub Pages.

## Enabling GitHub Pages (one-time)

GitHub Pages must be turned on once from the repository settings (this step
needs repo-admin rights and cannot be automated):

1. Go to **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **Deploy from a branch**.
3. Set **Branch** to `claude/github-pages-hosting-xn4b2q` and folder to `/ (root)`.
4. Click **Save**.

After a minute the guide will be live at:

```
https://ottitsch.github.io/amrc-exam/
```
