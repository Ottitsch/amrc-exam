# AMRC — Visual Chapter Guide

A mobile-friendly visual study guide for AMRC (Applied Multivariate / Regression
& Classification, TU Wien — Prof. Dr. Peter Filzmoser).

The guide is a single self-contained `index.html` page hosted on GitHub Pages.
It is deployed automatically by the workflow in
`.github/workflows/deploy-pages.yml` on every push to this branch.

Once the workflow finishes, the site is available at the URL shown in the
workflow run's deploy step.
